# ろっくんの おんがくばこ（music/）

ろっくんの ゲームの きょくを、アルバムごとに まとめて きける おんがくアプリです。
ゲームの きょく 89きょく と、この アプリの ために つくった 8ビットの あたらしい きょく 11きょく（ぜんぶで 100きょく）。

- きく: `https://wingman0527.github.io/rokkun/music/`
- おうちの ひとむけの せつめい: `https://wingman0527.github.io/rokkun/music/about.html`

## ファイル
- `index.html` … アプリ（1まいで うごく。ドットの フォント・え・きょくの がくふ・おとの しくみ・プログラムが ぜんぶ はいって いる。おとは きく ときに その たんまつの なかで つくる）
- `about.html` … おうちの ひとむけの せつめい（ききかた・ホームがめんへの いれかた・データと あんぜん・権利表記）
- `manifest.webmanifest` … ホームがめんに いれた ときの なまえ・アイコン・たてむき（Android）
- `apple-touch-icon.png`（180）・`icon-192.png`・`icon-512.png` … アイコン

## きまり
- そとへの つうしんは ぜんぶ とめて いる（ページの CSP: `default-src 'none'`。スクリプト・スタイルは ページの なかの ものだけ、え と フォントは `data:` と この フォルダだけ、おとは たんまつの なかで つくった `blob:` だけ）
- ログイン・こうこく・かきん・かいせき タグ は ありません。「すきな きょく」と せっていは その たんまつの ブラウザに だけ のこります
- アプリの なかに そとへの リンクは ありません（せっていの「おうちの かたへ」は この フォルダの `about.html`）
- つよい てんめつは ありません。「うごきを へらす」の せっていでは キャラと おんぷが うごかない

## あたらしい 版を のせる とき
- `build.py --pages` で できた `dist/pages/music/` の ファイルを **ぜんぶ いっしょに** 入れかえる（なまえは かえない）
- この フォルダの そとの ファイル（ろっくん1・`pico/`・`bouken/`）は さわらない
- マージして 1ぷんくらいで ひらける ように なる。ブラウザに よっては 10ぷんくらい まえの 版が でる ことが ある（いますぐ たしかめたい ときは アドレスの うしろに `?v=すうじ` を つける）
