# ろっくんの ピコピコ ものがたり（pico/）

はの なかまたちの くにを たびする、8ビットの RPG です（やく 1じかん）。
にゅうしの キバせんぱいの「そつぎょう」までの、さいごの たびの おはなし。

- あそぶ: `https://wingman0527.github.io/rokkun/pico/`
- おうちの ひとむけの せつめい: `https://wingman0527.github.io/rokkun/pico/about.html`

## ファイル
- `index.html` … ゲーム（1まいで うごく。ドットの フォント・え・おと・プログラムが ぜんぶ はいって いる）
- `about.html` … おうちの ひとむけの せつめい（あそびかた・ホームがめんへの いれかた・データと あんぜん）
- `manifest.webmanifest` … ホームがめんに いれた ときの なまえ・アイコン・よこむき・ぜんがめん（Android）
- `apple-touch-icon.png`（180）・`icon-192.png`・`icon-512.png` … アイコン

## きまり
- そとへの つうしんは ぜんぶ とめて いる（ページの CSP: `default-src 'none'`。スクリプト・スタイルは ページの なかの ものだけ、え と フォントは `data:` と この フォルダだけ）
- ログイン・こうこく・かきん・かいせき タグ は ありません。セーブ・きろく・はみがきタイマーの スタンプは その たんまつの ブラウザに だけ のこります
- ゲームの なかに そとへの リンクは ありません（おうちの かたへ の ページは かけざんの ゲートの むこう）
- てんめつは 1びょうに 2.5かい いか。よみあげは たんまつの こえ だけ

## あたらしい 版を のせる とき
- `build.py --pages` で できた `dist/pages/pico/` の ファイルを **ぜんぶ いっしょに** 入れかえる（なまえは かえない）
- この フォルダの そとの ファイル（ろっくん1）は さわらない
- マージして 1ぷんくらいで ひらける ように なる。ブラウザに よっては 10ぷんくらい まえの 版が でる ことが ある（いますぐ たしかめたい ときは アドレスの うしろに `?v=すきな もじ`）

いまの 版: v1.0.7（M5.7）（build 9dadf00a）
