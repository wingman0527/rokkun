ろっくんの おくち だいぼうけんこのゲームについて

このゲームは、歯科衛生士科の学生がデンタルフェスの出し物として作った、無料のブラウザゲームです。

料金・広告・登録

  • 無料です。広告、課金、ログイン、会員登録はありません。

データの扱い

  • 名前・メールアドレス・写真などの個人情報を入力する場面はありません。
  • 遊んだ記録（クリアしたステージ、★、設定）は、お使いの端末のブラウザの中にだけ保存します。
  • Cookie と広告用の識別子は使っていません。何人くらいが遊んでくれたかを知るための集計（下の「遊んだ人数の集計」）だけを行っています。
  • 記録を消すときは、アプリ版の「せってい」→「データを けす」を押すか、ブラウザの設定でこのサイトのデータを削除してください。

遊んだ人数の集計（アクセス解析）

  • 何人くらいが遊んでくれたか、どこまで進めたかを知るために、はじめのページとアプリ版で、次のことを数えています: ページを開いたこと、「あそぶ」を押したこと、ステージを始めた・クリアした・途中でやめたこと（ステージの番号、むずかしさ、かかった秒数、★の数）、エンディングを見たこと、「ともだちに おしえる」を開いたこと。
  • あわせて、ブラウザとOSの種類、画面の大きさ、言語、どのページから来たか、おおまかな地域（IP アドレスから推定される国・都道府県・市区町村）が記録されます。
  • 名前、メールアドレス、端末の識別子は送りません。Cookie も使いません。人数は、IP アドレスとブラウザの情報から作る一時的な番号（毎月かわります）で数えていて、IP アドレスそのものは集計の記録に保存しません。ただし、サーバーの通信記録（ログ）には、運用と安全のために一時的に残ることがあります。
  • 集計には、制作者が管理するサーバー（オープンソースの集計ソフト Umami を、Railway（Railway Corp.）の上で動かしています）を使います。広告会社など、ほかの会社には渡しません。
  • ブラウザで「トラッキング拒否（Do Not Track）」を有効にしているときは、数えません。ブース版（booth.html）とこの説明ページでは、集計をしません。

通信

  • 最初にこのサイトからゲームを読み込みます。そのあとは、新しい版があるかを確かめるために、同じサイトの小さなファイル（version.json）を読みます。
  • はじめのページとアプリ版は、上の集計のために、集計用のサーバー（umami-production-c60dc063.up.railway.app）とも通信します。それ以外のサイトとは通信しません。ブラウザの仕組み（Content Security Policy）でも、この2つ以外への通信を止めています。
  • このサイトは GitHub Pages（GitHub, Inc.）で配信しています。GitHub は、セキュリティのために閲覧者の IP アドレスを記録します（GitHub の説明）。

読み上げ

  • ナビの読み上げには、端末に入っている声だけを使う設定にしています。ブラウザが「インターネット経由」と示す声は使わないので、読み上げる文をほかのサービスに送らないようにしています。端末に日本語の声がないときは、読み上げません。
  • アプリ版の「せってい」→「ナビの こえ」で止められます。

健康のために

  • 明るい部屋で、画面から離れて遊んでください。長い時間続けず、ときどき休みましょう。
  • 遊んでいて気分が悪くなったときは、すぐにやめてください。
  • 光の点滅は、1秒に3回以下にしています。

歯の情報について

  • ゲームの中の歯の知識は、一般的な内容です。診断や治療の代わりにはなりません。気になることは、かかりつけの歯科医院に相談してください。

制作について

  • 絵・キャラクター・音楽・効果音・文章は、このゲームのために作ったオリジナルです。制作には生成AI（Anthropic の Claude）を使い、制作者が指示・確認・修正しています。
  • ほかの作品のキャラクター・曲・画像は使っていません。
