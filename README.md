# ろっくんの おくち だいぼうけん

はの なかを ぼうけんしながら、はみがきの コツが まなべる 横スクロール アクションです。
デンタルフェス（歯科衛生士科）の 出し物として つくりました。

- `index.html` … はじめの ページ（あそびかたの えらびかた）
- `app.html` … アプリ版（スマホ よこむき・15ステージ・ずかん つき）
- `booth.html` … ブース版（パソコン・マウス・3ぷん）
- `version.json` … いまの 版の なまえと ビルド番号（アプリ版が あたらしい 版を みつける ときに つかう）
- `apple-touch-icon.png` … ホーム画面に いれた ときの アイコン

どの ファイルも 1まいで うごきます（インターネットに つながって いなくても OK）。
ログイン・こうこく・かきん は ありません。あそんだ きろくは その たんまつの ブラウザに だけ のこります。

## あたらしい 版を のせる とき
- フォルダの ファイルを **ぜんぶ いっしょに** 入れかえる（`version.json` が ないと、アプリ版の じどう こうしんが うごかない）
- マージして 1ぷんくらいで ひらける ように なる。ブラウザに よっては 10ぷんくらい まえの 版が でる ことが ある
- アプリ版（M5.6 から）は、タイトルの ひだりうえに 版の なまえ（M5.6 など）が でる。あたらしい 版を みつけると、タイトルで じぶんで よみなおす（あそんだ きろくは きえない）
- いますぐ たしかめたい ときは、アドレスの うしろに `?v=すきな もじ` を つけて ひらく（れい: `app.html?v=10`）
